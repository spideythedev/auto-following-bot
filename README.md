# Auto Follow Back Bot

Automatically follows back GitHub followers.
![Repo Banner](./repo-banner.png)

## Setup

```text
1. Create token at https://github.com/settings/tokens (scopes: user, read:user, user:follow)
2. Add to repo Secrets: `GH_PAT` = your token
3. Enable Actions```

**Runs every 6 hours.**
